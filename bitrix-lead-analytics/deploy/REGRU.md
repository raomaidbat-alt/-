# Установка на хостинг reg.ru

Подходит любой тариф виртуального хостинга reg.ru с PHP 8.1+ и MySQL (панель ISPmanager). Docker и Node.js не нужны: дашборд уже собран и лежит в `public/`.

Ниже пример для поддомена `stats.ufcstudio.ru`. Можно поставить и на основной домен, если он больше ни для чего не нужен.

## 1. Сайт и PHP

1. Панель хостинга → **Сайты** → **Создать**: имя `stats.ufcstudio.ru`. Если домен и хостинг оба в reg.ru, DNS-запись для поддомена появится сама. Если DNS у домена в другом месте, добавьте A-запись `stats` на IP хостинга (он указан в панели).
2. В настройках сайта выберите **PHP 8.3** (или 8.2, 8.1), режим **CGI/FastCGI** или **PHP-FPM**.
3. Проверьте расширения PHP: `pdo_mysql`, `curl`, `mbstring`, `sodium`. На reg.ru они обычно включены.
4. **SSL-сертификаты** → **Заказать** → бесплатный Let's Encrypt для `stats.ufcstudio.ru`. Включите перенаправление на HTTPS.

## 2. База данных

**Базы данных** → **Создать**: MySQL, кодировка `utf8mb4`. Запишите имя базы, пользователя и пароль. Хост обычно `localhost`.

## 3. Файлы

1. Загрузите архив проекта в **Менеджер файлов** в домашнюю папку (не в `www`) и распакуйте в папку `b24`. Получится `~/b24/public`, `~/b24/src`, `~/b24/bin` и т.д.
2. Укажите корень сайта на папку `public`: **Сайты** → `stats.ufcstudio.ru` → **Изменить** → **Корневая директория** → `/var/www/<ваш_логин>/data/b24/public`.
   Так наружу видны только дашборд и API, а `config.php` и код остаются закрытыми.

## 4. Настройка

Скопируйте `config.example.php` в `config.php` (в папке `~/b24`) и заполните:

```php
'webhook_url' => 'https://ВАШ-ПОРТАЛ.bitrix24.ru/rest/<id>/<токен>/',   // новый вебхук, право CRM
'dsn'         => 'mysql:host=localhost;dbname=<база>;charset=utf8mb4',
'user'        => '<пользователь БД>',
'password'    => '<пароль БД>',
'token'       => '<длинная случайная строка>',   // пароль для входа в дашборд
```

В секции `channels` пропишите свои источники (например, `'sources' => ['64']` у Telegram-канала). Если не знаете ID источников и стадий, настройте сначала всё остальное и посмотрите их в шаге 5.

Ключ шифрования (`encryption_key`) нужен, только если вы включите выгрузку пользовательских полей (`sync.custom_fields`). По умолчанию он не нужен.

## 5. Первый запуск

**Через SSH** (включается в панели, раздел «Доступ по SSH»):

```bash
cd ~/b24
php bin/install.php          # создать таблицы
php bin/inspect_fields.php   # посмотреть стадии и источники портала
php bin/sync_leads.php       # первая полная выгрузка
```

На виртуальном хостинге `install.php` может написать, что пропустил 2 триггера (нет прав SUPER). Это нормально: журнал истории всё равно только дописывается.

**Без SSH.** Создайте задание в планировщике (шаг 6) и временно поставьте ему запуск каждые 5 минут: первый прогон создаст таблицы и выгрузит лиды. Потом верните расписание раз в 2 часа.

## 6. Автообновление каждые 2 часа

**Планировщик (cron)** → **Создать**:

- Команда (путь к PHP смотрите в панели, у reg.ru это обычно `/opt/php/8.3/bin/php`):
  ```
  /opt/php/8.3/bin/php ~/b24/bin/install.php >/dev/null; /opt/php/8.3/bin/php ~/b24/bin/sync_leads.php >> ~/b24/var/log/cron.log 2>&1
  ```
- Расписание: минута `0`, час `*/2`, остальное `*`.

И второе задание раз в неделю для полной сверки (подтягивает пропущенное и помечает удалённые лиды):

```
/opt/php/8.3/bin/php ~/b24/bin/sync_leads.php --full >> ~/b24/var/log/cron.log 2>&1
```
Расписание: минута `30`, час `3`, день недели `0`.

## 7. Готово

Откройте `https://stats.ufcstudio.ru`, введите токен из `config.php`. В шапке будет зелёный индикатор **Live** и время последней синхронизации.

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| Белая страница или 500 | Логи ошибок в панели (раздел «Логи»), чаще всего не та версия PHP или нет `pdo_mysql` |
| В дашборде «Токен не подошёл» | Токен в браузере не совпадает с `api.token` в `config.php` |
| `{"error":"https_required"}` | Сайт открыт по `http://`: включите SSL и перенаправление на HTTPS |
| «Данные устарели» в шапке | Не работает cron: проверьте команду и путь к PHP, смотрите `~/b24/var/log/` |
| В логе `INVALID_CREDENTIALS` | Вебхук удалён или перевыпущен, обновите `webhook_url` |
| Нет каналов, всё в «Других источниках» | Не заполнены `sources` в `channels`, ID смотрите через `inspect_fields.php` |
