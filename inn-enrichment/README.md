# Обогащение компаний по ИНН

Берёт выгрузку компаний (CSV или XLSX с колонкой «ИНН»), по каждому ИНН находит телефоны, email, сайт и мессенджеры и сохраняет XLSX: исходные колонки остаются как были, новые добавляются справа и подсвечены жёлтым.

Работает бесплатно, ключи не нужны. Контакты берутся с сайта компании:

1. **Поиск сайта.** Если в файле есть колонка «Сайт», проверяется он. Иначе скрипт ищет в DuckDuckGo (при отказе в Bing) запрос `"ИНН"`, а потом `название ИНН`. Агрегаторы вроде Rusprofile, List-org, Checko, справочники, соцсети и госсайты отбрасываются. Сайт принимается, только если на нём указан именно этот ИНН, так что чужой сайт в результат не попадёт.
2. **Контакты с сайта.** Скрипт открывает главную и до четырёх страниц вида «Контакты», «О компании», «Реквизиты», собирает ссылки `tel:` и `mailto:`, номера и адреса из текста, ссылки на Telegram, WhatsApp, VK, MAX. 
Если есть ключ **DaData** (необязательно), дополнительно подтягиваются статус компании и руководитель, а на платном тарифе «Максимальный» ещё телефоны и email из реестров. Если в строке есть КПП, ищется именно этот филиал.

## Какие колонки добавляются

| Колонка | Что в ней |
|---|---|
| Статус (DaData) | действует, ликвидирована, банкротство (только с ключом DaData) |
| Руководитель (DaData) | ФИО и должность, у ИП ФИО предпринимателя (только с ключом DaData) |
| Основной телефон | первый мобильный, если мобильных нет, то первый городской |
| Телефоны мобильные / городские | все найденные номера в формате `+7 912 345-67-89` |
| Основной email | первый именной, если именных нет, то первый общий |
| Email именные | адреса конкретных людей: с фамилией руководителя или учредителя, вида `i.ivanov@`, либо личные ящики на mail.ru, yandex.ru, gmail.com |
| Email общие | `info@`, `sales@`, `office@` и прочие ролевые |
| Сайт | рабочий адрес сайта |
| ИНН на сайте | да / нет |
| Мессенджеры и соцсети | ссылки с сайта |
| Источники | DaData, сайт, сайт (найден поиском) |
| Комментарий | почему данных нет: неверный ИНН, сайт с этим ИНН не найден, поиск заблокировал запросы |

Из ваших колонок используются «ИНН», «КПП», «Фамилия/Имя/Отчество руководителя» (по фамилии узнаются именные ящики) и «Название (ФИО)» (у ИП это ФИО владельца). Остальные просто переносятся в результат.

ИНН, испорченный Excel (`7707083893.0` или потерянный ведущий ноль у регионов 01–09), восстанавливается автоматически. ИНН с неверной контрольной суммой пропускается сразу.

## Чего ждать от бесплатного режима

Сайт находится не у всех. У крупных и средних компаний обычно есть сайт с реквизитами, у небольших ООО и ИП его часто нет вовсе, и тогда строка останется пустой с комментарием «сайт с этим ИНН в поиске не найден».

Поисковики не любят частые запросы, поэтому между запросами выдерживается пауза 2,5 секунды. Из-за неё 1 000 компаний обрабатываются примерно час, а то и два. Если поисковик всё же начал показывать капчу, в комментарии будет «поиск: поисковики недоступны», и такие строки не кэшируются: просто запустите тот же файл ещё раз позже, найденное ранее возьмётся из кэша.

Результаты кэшируются на 30 дней в `var/cache.sqlite`.

## Про DaData

Ключ необязателен. Бесплатный тариф DaData (10 000 запросов в сутки) даёт статус компании и ФИО руководителя, по фамилии руководителя точнее определяются именные email. Телефоны и email компаний DaData отдаёт только на платном тарифе «Максимальный». Если ключ не принят или лимит кончился, прогон останавливается сразу, файл не портится.

## Установка

Нужен Python 3.10+.

```bash
cd inn-enrichment
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Ключ DaData, если он есть, вписывается в файл `.env` (скопируйте `.env.example` в `.env`) или передаётся переменной окружения `DADATA_API_KEY`. Файл `.env` в git не попадает.

## Запуск

```bash
python -m enrich companies.xlsx                    # результат: companies_enriched.xlsx
python -m enrich companies.csv -o result.xlsx
python -m enrich companies.xlsx --no-search        # не искать сайт, проверять только колонку «Сайт»
python -m enrich companies.xlsx --no-site          # только DaData, без сайтов (нужен ключ)
python -m enrich companies.xlsx --no-cache         # не брать ответы из кэша
```

CSV читается в UTF-8 и Windows-1251, разделитель `;`, `,` или табуляция определяется сам. Уже обогащённый файл можно прогнать ещё раз: новые колонки перезапишутся, а не задвоятся.


## Персональные данные

Скрипт собирает только то, что компания или реестр публикуют сами: контакты с официального сайта и сведения ЕГРЮЛ/ЕГРИП через DaData. Личные телефоны руководителей из сторонних баз он не ищет. Именные ящики и мобильные номера сотрудников всё равно персональные данные по 152-ФЗ: для холодных звонков и рассылок нужна правовая основа, а для рекламных рассылок по email и SMS ещё и согласие получателя (ст. 18 закона «О рекламе»).

## Тесты

```bash
pip install pytest
python -m pytest -q
```

DaData и поисковик в тестах подменены заглушками, сайт поднимается локально, в интернет тесты не ходят.
