# Обогащение компаний по ИНН

Берёт выгрузку компаний (CSV или XLSX с колонкой «ИНН»), по каждому ИНН находит телефоны, email, сайт и мессенджеры и сохраняет XLSX: исходные колонки остаются как были, новые добавляются справа и подсвечены жёлтым.

Откуда берутся контакты:

1. **DaData** (`findById/party`): статус компании, руководитель, телефоны и email из реестров. Если в строке есть КПП, ищется именно этот филиал, иначе головная организация.
2. **Сайт компании.** Домен берётся из колонки «Сайт» (если она есть в файле) или из корпоративной почты, которую вернула DaData. Скрипт открывает главную и до четырёх страниц вида «Контакты», «О компании», «Реквизиты», собирает ссылки `tel:` и `mailto:`, номера и адреса из текста, ссылки на Telegram, WhatsApp, VK, MAX. Заодно проверяет, указан ли на сайте ИНН компании: так видно, что сайт точно её.

## Какие колонки добавляются

| Колонка | Что в ней |
|---|---|
| Статус (DaData) | действует, ликвидирована, банкротство |
| Руководитель (DaData) | ФИО и должность, у ИП ФИО предпринимателя |
| Основной телефон | первый мобильный, если мобильных нет, то первый городской |
| Телефоны мобильные / городские | все найденные номера в формате `+7 912 345-67-89` |
| Основной email | первый именной, если именных нет, то первый общий |
| Email именные | адреса конкретных людей: с фамилией руководителя или учредителя, вида `i.ivanov@`, либо личные ящики на mail.ru, yandex.ru, gmail.com |
| Email общие | `info@`, `sales@`, `office@` и прочие ролевые |
| Сайт | рабочий адрес сайта |
| ИНН на сайте | да / нет |
| Мессенджеры и соцсети | ссылки с сайта |
| Источники | DaData, сайт |
| Комментарий | почему данных нет: неверный ИНН, компания ликвидирована, сайт не открылся |

Из ваших колонок используются «ИНН», «КПП», «Фамилия/Имя/Отчество руководителя» (по фамилии узнаются именные ящики) и «Название (ФИО)» (у ИП это ФИО владельца). Остальные просто переносятся в результат.

ИНН, испорченный Excel (`7707083893.0` или потерянный ведущий ноль у регионов 01–09), восстанавливается автоматически. ИНН с неверной контрольной суммой в DaData не отправляется и лимит не тратит.

## Про тариф DaData

Телефоны и email компаний DaData отдаёт только на тарифе **«Максимальный»**. На бесплатном и «Базовом» эти поля пустые: скрипт всё равно отработает, но контакты будут только с сайтов, а сайт найдётся лишь у тех, у кого он указан в исходном файле. Проверить свой тариф можно в личном кабинете dadata.ru.

Лимит: 10 000 запросов к `findById/party` в сутки на бесплатном тарифе. Ответы кэшируются на 30 дней в `var/cache.sqlite`, поэтому повторный прогон того же файла лимит не тратит. Если ключ не принят или лимит кончился, прогон останавливается сразу, файл не портится.

## Установка

Нужен Python 3.10+.

```bash
cd inn-enrichment
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # вписать DADATA_API_KEY и DADATA_SECRET_KEY
```

Ключ можно не класть в `.env`, а передать переменной окружения `DADATA_API_KEY`. Файл `.env` в git не попадает.

## Запуск

```bash
python -m enrich companies.xlsx                    # результат: companies_enriched.xlsx
python -m enrich companies.csv -o result.xlsx
python -m enrich companies.xlsx --no-site          # только DaData, без сайтов (быстро)
python -m enrich companies.xlsx --workers 16       # больше потоков
python -m enrich companies.xlsx --no-cache         # не брать ответы из кэша
```

CSV читается в UTF-8 и Windows-1251, разделитель `;`, `,` или табуляция определяется сам. Уже обогащённый файл можно прогнать ещё раз: новые колонки перезапишутся, а не задвоятся.

Скорость: около 1 000 компаний за 3–5 минут с сайтами при 8 потоках, с `--no-site` в несколько раз быстрее.

## Персональные данные

Скрипт собирает только то, что компания или реестр публикуют сами: сведения ЕГРЮЛ/ЕГРИП через DaData и контакты с официального сайта. Личные телефоны руководителей из сторонних баз он не ищет. Именные ящики и мобильные номера сотрудников всё равно персональные данные по 152-ФЗ: для холодных звонков и рассылок нужна правовая основа, а для рекламных рассылок по email и SMS ещё и согласие получателя (ст. 18 закона «О рекламе»).

## Тесты

```bash
pip install pytest
python -m pytest -q
```

DaData в тестах подменена заглушкой, сайт поднимается локально, в интернет тесты не ходят.
